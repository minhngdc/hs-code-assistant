# Trang giới thiệu Nhóm 8 – Trợ lý phân loại mã HS

Website tĩnh 6 trang, không cần build:
index.html (Trang chủ), giai-phap.html, cong-nghe.html, doi-ngu.html, lo-trinh.html, tai-lieu.html,
cùng thư mục assets/ (style.css, app.js, ảnh).

## Đưa lên GitHub Pages
1. Trong repository của nhóm, tạo thư mục `docs` và tải lên TOÀN BỘ tệp trong gói này, giữ nguyên thư mục `assets`
   (Add file → Upload files → kéo cả thư mục → Commit changes).
2. Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, thư mục `/docs` → Save.
3. Link có dạng `https://<tên-tài-khoản>.github.io/<tên-repository>/`.

## Cập nhật nội dung
Nội dung nằm trực tiếp trong từng tệp .html. Các ô cần điền đang ghi trong ngoặc vuông, ví dụ
[email trường], [link Drive hoặc GitHub sau khi nộp], [URL GitHub của nhóm], [ngày].
Không đưa PDF gốc của thông báo (có tên doanh nghiệp, mã số thuế) lên repository công khai.
